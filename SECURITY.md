# Reporting security issues

Preparations for the public release are under way. There is no list of supported
releases or guaranteed response time yet.

Report a suspected leak of text or a token, a write to the wrong field or any other security
issue privately to the project's contact address: **info@gramadrama.app**.
Do not publish a working key, token, private correspondence or the addresses
of your own infrastructure in the report or in a screenshot.

Give the platform, the app version, the steps to reproduce with made-up text, and
the expected and actual result. Names of service types and anonymised examples
are enough, e.g. `https://api.example.com`. Review raw logs and settings before
attaching them; they may contain information about your environment.

A secret found in the repository history must be revoked with its issuer. Removing it
from the current file does not remove earlier copies. The rules for checking files are described
in the [repository policy](docs/repository-privacy.md).
