# GramaDrama — brand

**Slogan:** *Pisz bez dramatu.* / *Write without the drama.*

**Idea:** grammar + drama. Two theatre masks — the sad one is text with errors, the happy one is text after
the correction; the happy one stands in front. The tone of communication is light and tongue-in-cheek, but the
app itself is quiet and stays out of the way.

**Promises:** servers chosen by the user · no telemetry · Polish and English ·
works in Slack, Outlook and wherever you write.

## Colours

Each colour has one meaning, on warm neutral backgrounds. The dark version is a lighter shade
of the same colour.

| Role | Name | Light | Dark |
|------|------|-------|------|
| App actions (buttons, clickable suggestions, switches, focus) | Lavender | `#66579E` (hover `#574A88`) | `#BCB0EC` |
| What checking found (wavy underline under a word, counter) | Brick | `#D07A52` (wave), `#AD4E2C` (counter, text) | `#EBA27F` |
| Corrected text, “Working” (*Działa*), “No drama” (*Zero dramatu*) | Sage | `#536B60` (text), `#E9F0E9` (background) | `#ADC8B5`, `#34483C` |
| App error (e.g. the server is not responding) | Rose | `#9E3446` | `#F2A7AE` |
| Text / secondary text | Graphite | `#343337` / `#6B6870` | `#F1EEE8` / `#B9BDB8` |
| Surface / background / lines | Paper | `#FFFEFC` / `#F7F5F1` / `#DDD8D0` | `#242827` / `#181B1B` / `#505852` |

- Deleted text in diffs: struck through, in the secondary text colour (not in the error colour).
- Brick and sage have similar lightness. So an error and a correction also differ in shape: an error is a wave,
  a correction is a background or a dotted underline — not only colour.
- The active mode tab is neutral; lavender is kept for actions on the text.
- Contrast (WCAG 2.2 AA): lavender `#66579E` on `#FFFEFC` 6.1:1, white on it 6.1:1; brick `#AD4E2C`
  5.4:1; sage `#536B60` 5.7:1; disabled switch `#8E8992` 3.4:1.

Applied in: the GNOME extension, the website, the macOS app (`Sources/GramaDrama/Brand.swift`) and the
shared browser extension (`browser/extension/popup.css`). The app window on Linux keeps GNOME's neutral greys
(libadwaita) and takes only the lavender accent and the state colours (sage, brick, rose); the warm backgrounds
are for what GramaDrama draws over other apps.

## Logo

Two masks — the happy one in front, the sad one (slightly dimmed) behind it — light (`#FFFEFC`) on a lavender
rounded square `#66579E`, with no gradient and no tick. The eyes and mouths are cut out.

- Source: `linux/icon.svg` (the app icon on Linux). The website icons (`site/public/img`:
  `icon-192.png`, `apple-touch-icon.png`, `favicon.ico`) are made from it by `site/tools/icons.py`.
- In the panel and in the dictation pill only the masks, neutral, without the square
  (Linux: `linux/gnome-extension/icons/mask-*.svg`, macOS: `MasksLogo` in `Brand.swift`): filled after a result,
  outlined while working.

## Icons

- macOS app: `AppIcon.icns` (generated by `scripts/make-icon.swift` from the masks in `linux/icon.svg`,
  on the macOS icon grid square).
- Browser extension: `browser/extension/icons/icon*.png` from `linux/icon.svg` (`browser/tools/icons.py`);
  the `-off` version (page turned off or the app not running) has a grey square `#8E8992`.
- Menu bar: SF Symbol `theatermasks` (template, adapts to light and dark mode);
  `theatermasks.fill` while checking.

## Microcopy

- Checking: „Czytam scenariusz…” / “Reading the script…”
- Server error: „Serwer nie odpowiada — sprawdź połączenie.” / “The server is not responding — check the connection.”
